# Яндекс Чекап — корзина по рекомендации

Интерактивный демонстрационный прототип: сборка набора анализов, многоразовая ссылка, корзина получателя и статистика автора.

Цены, сроки и начисления демонстрационные. Реальных оплат и записей нет. Наборы и статистика сохраняются только в текущем браузере.

Для публикации в GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

Из корзины можно оформить заказ для себя или порекомендовать анализы. Создание ссылки не сохраняет набор автоматически: предложение сохранить появляется после отправки через меню «Поделиться» или копирования ссылки. Демостатистика учитывает рекомендации, даже если набор не сохранён.


## Версии прототипов

- [Предыдущий прототип — корзина по рекомендации](https://konigann.github.io/analyses-recommendations-prototype/) — сохранён как ориентир «что было».
- [Новая версия — кабинет специалиста](https://konigann.github.io/analyses-recommendations-prototype/specialist/) — назначения, шаблоны, черновики и финансы; без графического логотипа Яндекса. Скидка пациенту 10%, вознаграждение специалисту 10% от оплаченной суммы после скидки, после сдачи анализов.
