# Анализы — корзина по рекомендации

Интерактивный демонстрационный прототип: сборка набора анализов, многоразовая ссылка, корзина получателя и статистика автора.

Цены, сроки и начисления демонстрационные. Реальных оплат и записей нет. Наборы и статистика сохраняются только в текущем браузере.

Для публикации в GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).
